● The script is written, run end to end, and verified. Both files are
  uncommitted in the working tree.

  What I built: 00_Get_the_Data.R (code/00_Get_the_Data.R) downloads the TinyEHR
  dataset in MIMIC-IV format plus every piece of documentation I could find for
  it, using base R only. It is idempotent, so re-running skips files already
  present. Set the flag at the top to force a re-download, or to also pull the
  OMOP CDM copy.

  What it fetched into data/ (92 files, 144 MB, all succeeded):

  - Data: all 32 MIMIC-format tables (22 hosp, 9 icu, 1 notes) plus the
    per-patient date-offset metadata. TinyEHR calls these "33 tables".
  - TinyEHR docs: README, ABOUT_THE_DATA (every transformation applied to the
    source data), and the ODbL licence.
  - Upstream source docs: the PhysioNet MIMIC-IV Demo v2.2 README, licence,
    SHA256 checksums, and the list of 100 demo subject IDs.
  - Official MIMIC-IV table documentation: 51 markdown pages from the MIT-LCP
    repo behind mimic.mit.edu, covering every hosp and icu table, the schema
    overview, concepts, changelog, glossary, and the shared identifier
    definitions.
  - The MIMIC-IV paper: Johnson et al. 2023, Scientific Data, open access,
    confirmed to be a valid PDF.

  Verification: every table's row count matches the figures published in
  ABOUT_THE_DATA.md, including the 668,862-row chartevents and the multi-line
  noteevents file. A manifest at data/manifest_00_get_the_data.csv records each
  file's source URL, size, MD5, observed and expected rows, retrieval time, and
  the TinyEHR commit it came from.

  One side change: I added data/ to .gitignore so the downloaded CSVs are not
  committed. The script regenerates them.

  Two caveats worth knowing for the talk. TinyEHR shifts the MIMIC dates from
  the 2100s to the 2010s, and the 4,580 clinical notes were LLM-generated and
  not clinically validated. Both are documented in the ABOUT_THE_DATA file now
  sitting in data/documentation/tinyehr.
